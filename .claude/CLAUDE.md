## README 约定（文件夹本地记忆）

Vault 主要文件夹均有 `README.md`，底部包含 `## Claude 经验积累` 区块。

**两条规则：**
1. 在某文件夹内工作时，若有 `README.md` → **先读取**，了解该文件夹的结构与约定
2. 完成工作后 → 将本次经验追加到 `## Claude 经验积累`，格式：`- YYYY-MM-DD: 内容`

已有 README 的文件夹：`10-Action/`、`20-Card/`、`30-Time/`、`40-storage/`、`x-AI-Studio/`

**例外：`+/`（收件箱）没有 README，也不需要**——它是临时中转区，笔记进来就等着被分诊、归档到别处，不沉淀本地约定。在 `+/` 工作时直接开始，不要去找 README。

## 记忆写入规则

| 内容类型 | 写入位置 |
|---------|---------|
| 持久偏好、重要决策、用户特征 | `.claude/MEMORY.md` |
| 今日任务、当前上下文、临时记录 | `.claude/memory/YYYY-MM-DD.md` |
| 文件夹内操作经验、注意事项 | 该文件夹 `README.md` → `## Claude 经验积累` |
| Vault 全局约定与结构 | `.claude/MEMORY.md` → `## Vault 约定` |

**核心原则：文字 > 脑内记忆。用户说"记住"→ 立刻写入文件，不要只存在当前对话中。**
