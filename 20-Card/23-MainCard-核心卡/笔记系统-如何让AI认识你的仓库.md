直接对 AI 说「帮我整理笔记」——它会给你一个看起来有道理但跟你毫无关系的回答。因为它不认识你，不知道你的文件夹放的是什么，不知道你的卡片和目标之间是什么关系。

**让 AI 认识你的仓库，三步：**

**第一步：把系统告诉 AI**
让 AI 读取课程逐字稿（或仓库里的课程内容），了解 ACT 系统的设计逻辑，建立基础认知。

**第二步：为每个文件夹写 README**
README 是文件夹的自我介绍，AI 进入文件夹时自动读取。每次新会话，一句话让 AI 快速建立上下文：「请先读取每个主文件夹的 README」。

**第三步：安装基础 Skills**
Skill 是你教给 AI 的可复用工作流，存在仓库里的文件。每次需要用，直接触发，不需要重新解释。从四个基础 Skill 开始：每日开场、每日收场、收件箱归档、笔记分诊。

每次新开会话，AI 又是全新的——但有了 README 和 Skills，上下文恢复只需要一句话。
