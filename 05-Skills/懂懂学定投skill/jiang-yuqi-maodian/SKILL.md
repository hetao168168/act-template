# 降预期锚点 (年化 7% = 国家队)

## R — 原文 (Reading)

> 降预期，拉长线，年化7%的收益率就很牛逼，国家队也就这水平，至于年化10%以上？那是明星基金经理的水平，年化20%以上呢？世界级股神。
>
> — 懂懂, "青州老师洗脑"段

---

## I — 方法论骨架 (Interpretation)

散户最致命的误区不是"不够努力",而是**预期错位**——觉得"一年不翻倍就不值得炒"。

破局方法很简单: 建立一个**收益率基准刻度**,把模糊的"别贪"变成可对照的"你的预期对应哪个段位":

| 年化收益 | 段位 |
|---|---|
| 3% | 作者自己的预期(且大概率超过) |
| 7% | 国家队水平,已经很牛 |
| 10% | 明星基金经理水平 |
| 20%+ | 世界级股神(巴菲特/芒格) |

一旦看清这个刻度,两个反直觉结论就浮出来:

1. **追求"翻倍"不是野心,是无知**——你要求的是"世界级股神"的收益,却配着"普通散户"的能力。
2. **降预期不是保守,是复利的起点**——"没有人愿意慢慢变富",而慢慢变富恰恰是唯一能变富的路。作者预期只有 3%,却"拉长线看把大部分人甩在身后"。

一句话: 预期降下来,耐心才上得来。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 作者的 3% 预期
- **问题**: 定投的合理年化目标该定多少?
- **方法论的使用**: 用基准刻度对照,把预期压到 3%(国家队 7% 他都不奢求)。
- **结论**: "太低不至于,太高也不会太高",但拉长线能甩开大部分人。
- **结果**: 低预期支撑了"拿得住、不折腾",最终实现过千万持仓。

### 案例 2: 分享会旁座大哥 (反证)
- **问题**: 大哥说"你资金量大可以慢慢赚,我本金少只能抓高收益率赚快钱"。
- **方法论的使用**: 借段永平的话点破: 这可能是你一直没钱的原因。
- **结论**: 高预期 → 博高波动 → 无法复利 → 永远本金少,是恶性循环。
- **结果**: 揭示"降预期"是打破穷人循环的关键。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户设定投资目标时,给出明显偏高的收益预期
2. 用户说"年化 20% 才值得做""本金少必须博高收益"
3. 用户拿某个高收益产品/大 V 战绩做对标,问"我能不能也做到"

### 语言信号 (用户的话里出现这些就应激活)

- "一年能不能翻倍" / "20% 收益太低了吧" / "本金少要博高收益"
- "我想做到年化 30%" / "巴菲特也不过 20%" / "多少收益才算合格"
- 英文: "what's a realistic return" / "is 20% annual return achievable" / "target return rate"

### 与相邻 skill 的区分

- 与 `xian-kan-dao-jieguo` 的区别: 那是"把结果想具体"(管别放弃),这是"把预期压低"(管别贪)——一个管下限动力,一个管上限理性。
- 与 `shifei-ji-chengbai` 的区别: 那是"对错纪律",这是"预期校准"——先校准预期,再谈执行纪律。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别用户当前的收益预期**
   - 完成标准: 让用户说出一个具体的年化数字目标。

2. **对照基准刻度定位段位**
   - 完成标准: 把用户的目标放到刻度表里(7%=国家队 / 10%=明星经理 / 20%=世界级),明确指出"你的预期对应哪个段位"。
   - 判停条件: 若用户目标已 ≤7% 且理性 → 无需再教育,跳到收尾。

3. **点破"高预期 = 无知 + 复利杀手"**
   - 完成标准: 说明"要求翻倍 = 要求世界级股神收益却配普通散户能力",且高预期会逼人去博高波动、破坏复利。

4. **给一个可落地的低锚点**
   - 完成标准: 建议一个理性区间(散户 3-7%),并说明"低预期反而能跑赢 99% 的人"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **已经理性低预期**: 用户已经清楚"慢慢变富",再教育是多余。
- **专业/机构投资者**: 面对真正有能力追求超额收益的选手,段位刻度不适用(他们就是那 1%)。

### 作者在书中警告的失败模式

- **觉得自己更聪明** (ce02): 99% 散户赚不到钱,根因是"觉得自己比平均水平强",去和全球最聪明的人做对手盘。
- **嫌慢/求快** (ce03): "本金少→要赚快钱"的穷人循环,正是高预期造成的。

### 作者的盲点 / 时代局限

- **本金安全判停** (p01 合并警示): 降预期的前提仍是"本金不亏";不能为追求低风险而忽视"永不亏本"这条底线。
- **牛市后视镜** (来自阶段 0 批判): "3% 也能过千万"依赖的是长牛 + 大本金 + 不断供,普通人复刻需先有流动性保障。

### 容易混淆的邻近方法论

- **风险偏好评估 (risk tolerance)**: 那测的是"你能承受多大波动";本 skill 校准的是"你该期待多高收益",两者相关但不同——一个是承受力,一个是期望值。
- **`guimo-jueding-shu` (规模决定术)**: 用户说"资金不大/本金少,想设激进止盈线/网格"——只要落点在**参数怎么设**,归 `guimo-jueding-shu`;本 skill 只管"收益目标/预期该定多高",不负责具体参数设计。
