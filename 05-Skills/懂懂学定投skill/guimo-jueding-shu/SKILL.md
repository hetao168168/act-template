# 规模决定术 (术随规模演化)

## R — 原文 (Reading)

> 要参考规模，500万，1000万，5000万，绝对不能使用同一套定投方案。……术，并不重要。核心是道，你要理解，定投到底是个什么玩意？
>
> — 懂懂, "定投额度与收割比例"段

---

## I — 方法论骨架 (Interpretation)

定投的"术"——止盈线、每期额度、要不要网格——**不是一套普适的最优参数,而是当前状态的函数**。

具体由三个变量决定:

1. **资金规模**: 你有多少存量本金。
2. **持续投入速度**: 每月/每周能投多少新钱。
3. **心理成熟度 + 收益最大化**: 你能承受多大回撤、想要多优的复利。

作者的止盈线走了三步,每一步都对应不同规模:

- **早期**(本金少、每天投 5000): 止盈线 20%,两年靠"每天止盈 + 每天定投"实现自循环。
- **2025 年**(500 万+ 后勤资金待命): 止盈线提到 50%,因为钱多、一次投不进,需要更长的持仓周期。
- **2026 年**(规模更大): 每周 5500 + 网格交易、不再止盈——因为"规模越大,单笔定投对成本影响越小,定投价值也越小"。

核心洞察: **术不重要,道才重要**。别去抄"止盈设 20%"这个数字,要理解"在我当前的规模下,什么参数才自洽"。所以作者说: 即便穿越回 2018 年,他依然会走三步曲,而不是直接套用今天的策略。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 止盈三步曲 (20% → 50% → 不止盈)
- **问题**: 定投的止盈线和额度该如何定?
- **方法论的使用**: 不找"最优解",而是根据规模演化参数——早期 20%(两年自循环)→ 中期 50%(资金多待命)→ 后期不止盈 + 网格(规模大到单笔定投影响趋零)。
- **结论**: 每一步都是"资金量变化 + 心理成熟度 + 收益最大化"综合考量的结果。
- **结果**: 三步曲对应三种规模,证明"术随规模变"而非"存在一套最好方案"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户看到大 V / 教程给出"止盈设 20%、每周投 5000"等具体参数,想照抄
2. 用户定投到一定规模后,发现原来的参数"不好使了",问该怎么调
3. 用户问"我现在有 X 万,每月能投 Y,该怎么设止盈/额度/网格"

### 语言信号 (用户的话里出现这些就应激活)

- "别人说止盈设 20%,我照做行吗" / "定投参数怎么定"
- "我资金量变了,还要不要原来的方案" / "怎么设网格/仓位"
- 英文: "what's the best take-profit percentage" / "how much should I invest each month" / "copy this strategy"

### 与相邻 skill 的区分

- 与 `zhi-xuan-zhishu-jijin` 的区别: 那是"选什么标的(道)",这是"标的定好后怎么定参数(术)"——先有标的,再谈参数。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **量化用户的三个变量**
   - 完成标准: 问出并记录 ① 存量资金规模 ② 每月/每周可持续投入额 ③ 心理承受的回撤幅度。

2. **反推自洽参数(而非给"最优值")**
   - 完成标准: 用"规模 + 投入速度"推导: 本金少→短周期止盈(如 20%)以尽快自循环;本金大→拉长周期或不止盈 + 网格。
   - 判停条件: 若用户只想"要一个数字"而拒绝说明自己的规模 → 暂停,解释参数必须先锚定规模。

3. **显式否定"普适最优参数"**
   - 完成标准: 明确告知"500 万和 5000 万绝不能用同一套方案",并说明他抄来的那个数字对应的是别人的规模。

4. **把注意力从"术"拉回"道"**
   - 完成标准: 让用户能说出"我要理解的是定投的本质,不是某个参数"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **标的未定**: 还在纠结"买什么"(个股/基金/黄金)时,先走 `zhi-xuan-zhishu-jijin`,参数是之后的事。
- **宏观层问题**: "该不该定投""定投能不能赚钱"是"道"层,不是本 skill 的"参数层"。

### 作者在书中警告的失败模式

- **嫌慢/求快** (ce03): 因"本金少"而追求高收益率去博高波动,陷入"本金少→求快→亏损→本金还是少"的恶性循环——参数设定的心理陷阱。
- **不懂不碰** (p04 合并警示): 照抄大 V 的术却不理解其规模与上下文,等于在不懂的领域做决策。

### 作者的盲点 / 时代局限

- **本金安全判停** (p01 合并警示): 任何参数调整,先问"新参数是否仍保本金安全";若追求收益最大化而牺牲本金,一律不采纳。
- **流动性沉默** (来自阶段 0 批判): "规模决定术"默认你有充足后勤资金;无本金者需额外考虑"突发开支"这一约束,作者文中未提及。

### 容易混淆的邻近方法论

- **仓位管理 (position sizing)**: 仓位管理是"单笔风险控制";本法更宏观,是"整套定投参数(止盈/额度/网格)如何随规模演化",且强调"没有普适解"这一反直觉结论。
