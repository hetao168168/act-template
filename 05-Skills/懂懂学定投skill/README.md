# 懂懂学定投 · Skill 合集

从《懂懂学定投》（懂懂）蒸馏出的 **5 个 R-I-A-E-B 结构化子技能**，相互独立又互相组合，覆盖「选标的 → 校准预期 → 构造信仰 → 守住纪律 → 演化参数」的完整长期定投方法论。

## 一、五个技能速览

| 子技能 | 类型 | 一句话内核 | 触发信号 |
|---|---|---|---|
| **zhi-xuan-zhishu-jijin**（只选指数基金） | 道·选标的 | 三标准（净化/不退市/长期新高）筛标的，有且只能选指数基金 | 定投买什么 / 选股vs指数 / 买房还是买指数 |
| **jiang-yuqi-maodian**（降预期锚点） | 道·校准预期 | 年化刻度：3%=作者 / 7%=国家队 / 10%=明星经理 / 20%=世界级股神 | 翻倍 / 20%太低 / 本金少博高收益 |
| **xian-kan-dao-jieguo**（先看到结果） | 道·信仰构造 | 长期不靠意志力，靠把结果折算成具体生活画面 + 测算加固 | 坚持不下去 / 想放弃 / 长期没回报 |
| **shifei-ji-chengbai**（是非即成败） | 术·执行纪律 | 错的事与金额无关，1万玩玩也不碰，防知行分离 | 拿1万玩玩 / 破例 / 手痒追热点 |
| **guimo-jueding-shu**（规模决定术） | 术·参数演化 | 止盈/额度/网格是「规模+投入速度+心理」的函数，非普适 | 止盈设多少 / 抄大V参数 / 网格怎么设 |

## 二、主流程链（道 → 术）

```
① 只选指数基金  →  ② 降预期锚点  →  ③ 先看到结果  →  ④ 是非即成败  →  ⑤ 规模决定术
   选对标的          校准预期          构造信仰          守住纪律          演化参数
```

> 「只选指数」+「先看到结果」是全文唯二法宝的两半（拥抱指数 + 拥抱时间）。

## 三、触发分流决策树

- 问「买什么 / 选股vs指数 / 买房vs指数」→ **只选指数基金**
- 喊「翻倍 / 年化20% / 本金少要博高」→ **降预期锚点**
- 说「坚持不下去 / 想放弃 / 十年才见效」→ **先看到结果**
- 想「拿1万玩玩 / 破例一次 / 手痒」→ **是非即成败**
- 问「止盈设多少 / 抄参数 / 网格」→ **规模决定术**

## 四、作者盲点 / 使用边界（务必保留）

1. **「指数必然新高」是经验归纳，非逻辑必然**——日本日经 1989→2024 失落 30 年为反例；需地域分散（全球指数）对冲。
2. **「先看到结果」不能替代流动性安全垫**——作者踩中大牛市且本金大、不断供；无本金者先解决突发开支约束。
3. **本金安全是最高判停线**（p01）：任何调整若牺牲本金安全一律不采纳。
4. **「不懂不碰」**（p04）：散户选指数正因不懂个股；是非判断前提是真懂对错。
