# cangjie-skill 对话提示词速查卡

> 用途：把书 / 长视频转录 / 播客 / 课程，蒸馏成一组可执行的 Agent Skills（RIA-TV++ 七阶段流水线）。
> 适用环境：Claude Code（全局 `~/.claude/skills/` 或 ACT 库内 `.claude/skills/`）、WorkBuddy、Codex（`~/.codex/cangjie-skill/`，靠 AGENTS.md 指向）。

---

## 一、怎么让 AI 调起这个 skill

**方式 A — 直接描述意图（自动匹配）**
话里出现「拆书 / 蒸馏成 skill / 做成 skill」等词，AI 会自动加载 cangjie-skill。

**方式 B — 点名调用（推荐，最稳）**
句首或句中带出 skill 名：
> 用 cangjie-skill 把《XXX》拆成一组可执行的 skill

> 提示：Claude Code 没有固定 `/cangjie-skill` 斜杠命令，靠「自动识别 + 点名」即可，无需记命令。

---

## 二、必须提前给 AI 的两样东西

skill 规定「不凭记忆拆书」，所以你要提供：

1. **文本来源**：PDF / EPUB / TXT / 字幕 / 转写稿的**路径**（视频、播客要先转写成文本）
2. **元信息**：书名 + 作者 + 出版年（视频填 标题 + UP主/主播 + 时间）

---

## 三、可直接复制的提示词模板

### 拆一本书（最常用）
```
用 cangjie-skill 把这本书蒸馏成一组可执行的 skill：
- 文本：D:\books\穷查理宝典.pdf
- 书名：《穷查理宝典》 作者：查理·芒格 / 彼得·考夫曼 出版年：2005
- 输出语言：中文
```

### 拆一个视频 / 播客（先转写）
```
用 cangjie-skill 把这个视频的转写稿蒸馏成 skill：
- 文本：D:\transcripts\angular课程.txt
- 标题：《XXX》 UP主：XXX 时间：2025-xx
```

### 一次性批量（必须显式说「批量」，否则默认先试点 1 本）
```
用 cangjie-skill 批量蒸馏这几本书（文本路径已就绪）：
1. D:\...\书A.pdf —— 《书A》作者X
2. D:\...\书B.epub —— 《书B》作者Y
```

## 四、对话中会经历的确认节点（提前知道，别慌）

cangjie-skill 走 RIA-TV++ 七阶段，会在关键处停下来问你：

- **阶段 0 后**：确认「我对这本书骨架的理解对不对」
- **阶段 1.5 后（★重要）**：列出「通过验证的 N 个候选 + 淘汰的 M 个」，问你「有没有要捞回或砍掉的」——这一步确认能避免后面大量返工，建议认真回
- 阶段 2–4 最耗时，它会自己跑完再汇报

所以发出指令后不是等它一口气吐结果，而是**会被问几次**。

---

## 五、好用技巧

- **第一次用先试点**：说「先帮我试点这一本」，它遵循「永远先试点 1 本」惯例，验证顺了再批量。
- **指定语言**：加一句「输出用中文」，避免默认英文。
- **续跑**：中途断了不用重来，它每阶段会写 `PIPELINE_STATE.md`，下次说「从上次进度继续」即可。
- **全局 vs 项目级**：装在 `~/.claude/skills/`（全局，任意目录可用）和 ACT 库 `.claude/skills/`（在 ACT 库目录里跑 Claude 时也能用），两种场景都覆盖。

---

## 六、前置提醒

- 视频 / 播客没有现成字幕或转写 = 无法蒸馏，得先转成文本再喂给它。
- 蒸馏产出的最终 skill 会装到对应环境的 skills 目录（WorkBuddy → `~/.workbuddy/skills/`；Claude → `~/.claude/skills/` 或 `.cursor/skills/`），这一步不做则产物无法被真正调用。
